# GEARHEART #1: The Forge Awakens (Prologue + Pages 1-3)

An interactive comic prototype. All art is hand-authored SVG generated by plain JavaScript. No build step, no network, no dependencies.

## Open it

Double-click `index.html`. It runs from `file://` in any modern browser.

## Controls

- **Prev / Next buttons** or **Left / Right arrow keys**: turn the page (Prologue, Page 1, Page 2, Page 3). Home / End jump to the first / last page.
- **Shield Lab** button, or click the Shield panel on Page 3: opens the Shield demo.
  - **State** button: toggles the Shield between DORMANT and ACTIVE (gears spin, planet gears orbit, motion blur lines, sparks).
  - **Hover** over the Shield to aim: the nearest planet gear slides into the line of fire.
  - **Click** to fire a projectile; the planet gear blocks it with a spark burst.
  - **Auto-fire** button fires at random angles. **Esc** closes the lab.
- `prefers-reduced-motion` is respected: spinning is off and the lab's movements snap instead of animating.

## Files

- `index.html`: page shell, navigation, Shield Lab dialog
- `style.css`: layout, caption boxes, speech bubbles, SFX, Shield animation
- `js/art.js`: all SVG art (panels and the Shield)
- `js/app.js`: page/panel layout data, script text, navigation, Shield Lab logic
- `check.js`: optional sanity check (`node check.js`) that renders the SVG and confirms it is well-formed
